## 🚀 Featured Projects

### 🚦 NARASI

> **Interactive transport policy laboratory**

A client-side simulation lab modeling TransJakarta Corridor 1 (Blok M ↔ Kota), built around a PKM-GFT 2026 research proposal. Features:

* ⚙️ Deterministic simulation engine (<1 ms, pure functions, unit-tested with Vitest)
* 🎛️ 6 policy levers: headway, fleet size, EV ratio, dedicated lanes, feeder connectors, demand
* 📊 8 KPIs + multi-objective radar scoring (mobility, adoption, environment, economy, access)
* 🗺️ Geospatial corridor map with MapLibre GL + Deck.gl
* 🔬 Scenario comparison workbench & digital twin maturity view

**Tech Stack:** React • TypeScript • Vite • Zustand • MapLibre GL • Deck.gl • Turf.js • Recharts • Vitest

➡️ https://github.com/miralami/NARASI-National-Adaptive-Regional-Architecture-for-Simulation-Infrastructure

### 🏭 ERP PT. Marhadi

> **Logistics ERP built from scratch**

A production ERP system developed from scratch for PT. Marhadi's logistics operations. Features include:

* Order management with customer-specific pricelists (with Excel import/export)
* Delivery notes with status tracking, photo proof, and printable documents
* Fleet management: vehicles, drivers, brands, vehicle types, cities
* Invoicing with owner approval workflow and PDF generation
* Role-based access control (admin / staff / owner) and activity logs

**Tech Stack:** Laravel • Blade • PHP
